# SUARA PBB — PGRI Jateng Bagian Barat

Portal informasi dan aspirasi PGRI Jateng Bagian Barat.

## Cloudflare Pages

- Framework preset: **Vite**
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`
- Target custom domain: **suara.pgrijatengbarat.id**

## Migrasi
Tahap awal memindahkan frontend publik dan halaman berita statis agar ramah crawler WhatsApp/Open Graph. Modul redaksi dinamis akan dipindahkan pada tahap berikutnya ke Cloudflare Workers/D1.
